# 🧪 Labs

Espace personnel dédié à l’apprentissage, à la pratique et à l’expérimentation en informatique.

## 🎯 Objectif

Ce repository regroupe mes différents laboratoires d’apprentissage et mes exercices pratiques réalisés au cours de mon parcours en informatique.

L’objectif est de renforcer progressivement mes fondamentaux, développer mes compétences techniques et conserver une trace de ma progression.

## 📚 Contenu

Les labs peuvent notamment couvrir :

* 💻 Langages de programmation
* 🧠 Algorithmique
* 🗄️ Bases de données
* 🌐 Réseaux
* 🐧 Linux et systèmes
* 🔐 Cybersécurité
* ☁️ Cloud et infrastructure
* 🐳 Docker et outils de développement

## 🧪 Méthode de travail

Chaque exercice suit autant que possible une démarche personnelle :

**Réflexion → Algorithme → Codage → Compilation/Exécution → Tests → Correction → Validation**

Les exercices peuvent provenir de mes cours universitaires, de recherches personnelles, de challenges ou d'idées personnelles.

## 📈 Progression

Ce repository constitue une trace de mon apprentissage et de mon évolution technique au fil du temps.
